bex v1.0.0

Native Linux performance monitor built with C++20 and Qt 6.

GitHub Releases (AppImage, .deb, .rpm, Arch, source) · Source Code

Arch Linux (pacman repo)

Add to /etc/pacman.conf:

[bex]
SigLevel = Optional TrustAll
Server = https://kidusm001.github.io/bex/arch/$arch

Then install:

sudo pacman -Sy bex

Fedora (dnf repo)

sudo dnf config-manager addrepo --from-repofile=https://kidusm001.github.io/bex/rpm/bex.repo
sudo dnf install bex

Debian 12 (bookworm) / Ubuntu 24.04 (noble) (apt repo)

echo "deb [arch=amd64 trusted=yes] https://kidusm001.github.io/bex/apt $(. /etc/os-release && echo $VERSION_CODENAME) main" | sudo tee /etc/apt/sources.list.d/bex.list
sudo apt update && sudo apt install bex

Any Linux Distro (AppImage)

curl -fsSLO https://github.com/kidusm001/bex/releases/latest/download/bex-1.0.0-x86_64.AppImage
chmod +x bex-1.0.0-x86_64.AppImage
./bex-1.0.0-x86_64.AppImage

NixOS / Nix

nix run github:kidusm001/bex
